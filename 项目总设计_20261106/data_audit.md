# 数据清点：来源、测量内容、用途与进度

核对日期：2026-11-06。先读本文件了解数据；对接规则见[integration_design.md](integration_design.md)。各实验的较完整原始说明见[数据集来源与测量内容](../data/数据集说明_来源与测量内容.md)。

## 1 已有文件和已有实验不是同一个数量

下载清单78/78完成，约102.71 GB原文件，分布在12个原始目录。下面按13个研究数据项介绍：LINCS两期合并介绍，GDSC1/2及sci-Plex2/3分别介绍，所以项目数与目录数不同。MCF10A另外找到的4个RNA-seq对照单独记录，不混进原78个完成率。

本轮`file_inventory.csv`逐条核对下载状态记录、磁盘存在和文件大小。沿用此前完整性校验记录，不声称本轮重新对102.71 GB做了全量哈希。小型v2输入本轮另存SHA256指纹。

## 3 主实验输入输出的量纲

| 字段 | 量纲/含义 | 处理 |
|---|---|---|
| CCLE背景 | log2(TPM+1)，未处理RNA表达 | 作为背景编码器输入；特征缩放只在训练集拟合 |
| L1000 L5响应 | 相对参考的z分数，978维 | 直接作为响应目标；不与CCLE数值相加减 |
| dose_uM | μM浓度，均大于0 | 输入log10(μM)；vehicle用独立标记及mask处理，避免log(0) |
| expression_time_h | 3h、24h | 两个目标时间；不是两个独立72h功能样本 |
| relative_cell_count | Nt/Nc，无量纲 | 主功能回归目标；保留大于1的值 |
| relative_net_growth | (Nt−N0)/(Nc−N0)，无量纲 | 同一计数派生的解释/稳健性终点，允许负值；与Hafner GR公式区别记录 |
| library_id / source_file / references | 实验设计、重复与原孔来源 | 划分和误差分析的分组字段；主模型不靠库板ID记忆答案 |

MCF10A身份已正确映射`ACH-001357`，24Q4实际没有RNA profile和对应表达行；文件与读取错误已排查，官方文件没有说明其上游未覆盖原因。独立GSE152410的4个0h PBS RNA-seq已找到并下载，汇总为60554个Ensembl基因；974/978基因符号可唯一对应，PIK3R3/PAK6存在一符号多基因，HDGFRP3/PLSCR3需别名/稳定ID核查。下一步核查培养条件和ID后，在单独背景方案中评估第六种细胞。详见[原因追查](../data/investigation_20261106/MCF10A为何缺行_原因追查.md)。

第107个药是WH-4-025（`BRD-U60236422`）。Phase II `canonical_smiles`与`inchi_key`字段实际写的是`restricted`，所以当前缺的是可公开解析结构，不是已证实没有表达或功能。下一步核对作者论文/公开化学登记的同一物质结构；解析后经身份审核再加入，不能凭近名物质代替。

13条五种细胞内的条件未同时有3/24h，应继续定位缺哪个时间和来源；在允许缺标签的扩展方案中，可先使用已观测任务。主比较暂以双时间完整子集保持不同模型的监督预算一致。

## 5 本轮新增的重复和结构核查

结果源自[实验准备包audit.json](../data/prepared_20261106/HMS_v3_实验准备/audit.json)：

- 核心三批功能均值两两Spearman约0.953、0.937、0.943；各库板条件三批标准差中位数0.0501、95%分位0.1419。它们是描述统计，条件之间共享药物、细胞和剂量结构，不据此作独立样本显著性推断。
- 239个跨库板重复条件的相对细胞数绝对差中位数0.0240，最大0.8242。3h、24h跨库板表达相关中位数约0.331、0.594。部分差异值得追查：弱响应、板效应、化合物批次等需用原实例和对照区分，当前没有把某一解释认定为原因。
- 表达签名含1/2/3/4个实例者分别81/753/5079/901条。81条缺少`distil_cc_q75`，全部且仅仅是单实例签名；一个实例没有成对重复可算这一指标，不能因此自动判为文件损坏。原实例列表长度与该计数逐条一致。
- 106药没有保守连接结构重复；骨架组105。保留立体信息用于化学身份，以忽略立体的连接结构分组仅作保守数据划分。
- 两期`pr_is_lm=1`基因均为相同978个；`delta_landmark`另表仅785个重合，不能直接替代。

这些检查支持进入分层QC和基线实验准备；尚未把全部签名认定为通过生物学入组。真实弱响应需要保留，质量阈值不按功能标签或测试性能来挑。

进一步回读原孔发现：最大的五个跨库板功能差都来自CGP-60474、0.04 μM。642个该药原孔的Nt/Nc重算支持作者比例，差异在各生物重复均存在，已排除本项目聚合/比例计算造成的解释；实际物质、暴露、协议或原注释仍待查。原孔、曲线和设计影响见[专项追查](../data/investigation_20261106/CGP60474_跨库板差异/说明.md)。
