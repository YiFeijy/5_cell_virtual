# 01 研究框架

你的[整体框架原文](framework.docx)提出的问题是：药物处理既会改变细胞数量，也会改变细胞内部的分子响应。我们希望学习这两方面的联系，预测没有测过的给药条件，帮助选择值得实验验证的药物及方案；进一步研究第一次用药造成的变化如何影响后续用药。

因此，整个研究按五部分逐步展开：

| 部分 | 要回答的问题 | 当前实际位置 |
|---|---|---|
| ① 单药功能与状态 | 给什么药、多少剂量后，功能怎样变化、表达怎样响应？两类信息怎样关联、能否共同学习？ | 已完成一轮表达/功能预测比较；多来源部分标签学习、组成及状态参考研究仍待开展 |
| ② 新细胞迁移 | 学到的规律能否用于另一种细胞背景？哪些规律共享、哪些依赖细胞？ | 整体设计阶段 |
| ③ 同时联合 | 单药响应和状态信息，是否帮助预测两药同时使用的效果？ | 整体设计阶段 |
| ④ 序贯用药 | 第一次给药后的状态，是否帮助预测第二次给药？ | 整体设计阶段 |
| ⑤ 方案评价 | 加入状态信息后，是否真的选出更好的候选药物或给药方案？ | 本轮已做单药排序检查；完整方案评价仍待后续 |

**当前应集中理解①。** 它本身包括数据关联、表达与功能关系、状态验证、筛选评价。下面这轮训练先检验其中一个基础问题：同样的细胞、药物和剂量输入下，让模型同时学习表达与细胞数，是否比各自学习更有用。模型的中间向量是否代表真实药后状态，需要独立证据再检验。

要预测一次单药处理，首先要知道细胞是谁、药物是什么、剂量是多少；要检验预测，还需要真实实验答案。

| 需要的信息 | 在研究中做什么 | 本轮对应数据 |
|---|---|---|
| 给药前细胞背景 | 描述不同细胞的初始分子差异，作为输入 | CCLE/DepMap基线RNA |
| 药物身份、结构、剂量 | 描述施加的干预，作为输入 | LINCS药物说明和实际实验条件 |
| 处理后的表达响应 | 提供分子变化的实测答案 | LINCS L1000的24h响应 |
| 处理后的功能读数 | 提供功能后果的实测答案 | HMS的72h相对细胞数 |
| 独立的药后表达、组成或状态参考 | 后续验证模型是否描述了可重复的生物变化 | 已收集的其他表达数据，按各自实验进一步整理 |

这里有两个不同答案：**表达响应说明基因如何变化；相对细胞数说明处理后数量相对于对照是多少。** 表达变化很强是否一定对应细胞数明显下降，本身就是要调查的关系。先保留各自定义，再研究联系。
