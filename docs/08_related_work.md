# 08 相关工作怎样影响本研究

已有工作用于确定继承、对照和需要补充的证据。有先例不自动否决方向；把双任务、共享分支或状态层作为主模型，也不自动证明创新。

下面沿用2026-11-06已有核查记录，说明最直接的关系；完整字段保留原文出处及核查深度。

| 工作 | 研究内容与重合 | 本研究应怎样承接 |
|---|---|---|
| [Niepel et al.，2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5662764/) | 表达与生长/存活的关系和分歧 | 核对比较边界：原研究不是当前跨药物联合网络 |
| [Szalai et al.，2019](https://doi.org/10.1093/nar/gkz805) | 由表达预测活性；通用死亡/增殖签名及混杂 | 核对比较边界：功能关系及统计模型不等于当前基线到双目标 |
| [Dr.VAE，2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6761940/) | 潜在扰动映射及药敏分类 | 核对比较边界：每药单独模型；AAC二分类，不是跨药结构/连续剂量头 |
| [MIX-seq，2020](https://doi.org/10.1038/s41467-020-17440-w) | 活性相关/无关表达；早期表达预测药敏 | 核对比较边界：统计斜率/截距；曲线敏感性，不是独立同剂量72h计数 |
| [MultiDCP，2022](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1010367) | 扰动表达与剂量相关活性联合预测 | 核对比较边界：PharmacoDB曲线估计；当前HMS是平行条件实际计数 |
| [SequenTx，2026](https://doi.org/10.1038/s42256-026-01192-1) | 状态/活性模型与强化学习序贯策略 | 核对比较边界：当前仅单药数据准备，没有相应序贯结果 |
| [CPA，2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10258562/) | 未见条件的转录响应生成 | 核对比较边界：主要目标表达，非独立计数双任务 |

当前已有的是单药探索比较。完整贡献需要结合数据关联、泛化、筛选效果与独立状态验证逐项建立；先保留支持与不支持的方法结果，再据具体误差设计后续工作。
