# 06 根据结果怎样继续

下面是拟开展的顺序，本次梳理没有执行这些新实验：

| 顺序 | 为什么到这一步 | 具体做法与应该产出的答案 |
|---|---|---|
| ① 先定位现有误差 | 新药模型尚未超过强简单参照，排序没有改善 | 按药物、细胞、剂量、表达重复一致性检查误差；比较是否学到超过总体均值的药物差异。产出明确的问题分组和竞争解释，再决定模型或数据改动 |
| ② 检验额外表达监督 | 实测表达有功能预测信息，当前给药前模型尚未稳定用好 | 从已有LINCS资源增加表达训练/预训练，核对跨发布重复、测试药物及结构组泄漏；保持合理对照，并用新的冻结版本和独立留出评价增量。产出“哪些表达监督帮助了什么任务”的结果 |
| ③ 接回多来源数据关联 | 原框架要求利用部分对应、部分标签数据 | 优先把CTRP/GDSC形成带原剂量、对照处理和来源标识的功能长表，逐个实例核对；再比较同项目配对、部分可比和未配对监督。产出额外数据是否改善表达、功能及排序的证据 |
| ④ 研究状态真实性 | 原框架还要求区分群体组成与药后细胞状态 | 在MIX-seq、sci-Plex等实际条件中核对处理/对照和可用参考；设计组成、表达与独立功能的分别验证。产出状态信息的具体含义及其增量价值，再用于后续新细胞、联合及序贯任务 |

这里每一步都应先说明可检验的问题，再决定用哪个数据和方法。已有文献是比较基础；方法是否值得继承或改进，看它在实际问题上增加了什么证据。当前的正、负结果一起决定下一步。
