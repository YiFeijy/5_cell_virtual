# MCF10A为何未进入本轮CCLE背景一致的比较

问题是：HMS有MCF10A，为什么最终训练只有五种细胞？

按实际证据追查后，MCF10A身份为ACH-001357、RRID为CVCL_0598，模型匹配正确。固定的DepMap 24Q4表达矩阵没有该行；OmicsProfiles、默认profile及ModelCondition索引也没有相应公开RNA记录。原文件完整性校验通过，排除了下载损坏与主模型ID错误这两项解释。

因此已证实的原因层级是：**当前发布未提供这个模型的公开RNA profile。** 该发布的模型说明表覆盖范围大于RNA表达表，存在模型说明记录不等于存在RNA记录。上游为何未发布，现有README和索引没有交代。

继续查找后，还找到295个LJP溶剂对照表达，以及GSE152410的4个独立RNA-seq参照。后者培养条件不同，先保留来源与条件，再评价是否可作替代背景。本轮用统一CCLE背景开展五细胞比较；没有把替代来源直接插入CCLE文件。

核查详情见[身份与覆盖记录](../data/sources/mcf10a_identity_audit.json)，本轮输入与数量见[数据说明](02_data.md)。
