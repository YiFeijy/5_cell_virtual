# 02 数据是什么、为什么使用

## 本轮实际使用的三个来源

### CCLE / DepMap 24Q4：提供给药前背景

**来源：**Broad DepMap的[24Q4公开发布](https://doi.org/10.25452/figshare.plus.27993248.v1)。实际表达文件是`OmicsExpressionProteinCodingGenesTPMLogp1.csv`，一行对应一个细胞模型，一列对应一个基因，数值为`log2(TPM+1)`。它有**1,673行表达谱、19,193个蛋白编码基因列**；另有Model表及RNA profile索引，说明身份和测量覆盖。

**为什么用：**模型面对不同细胞时，需要可比较的初始特征。本轮从这个来源提取SKBR3、MCF7、HS578T、BT20、MDAMB231五种细胞的表达，并按LINCS实测的978个基因统一顺序，得到**5×978**的背景矩阵。优先使用两个来源都能明确定位、且在L1000中直接测量的基因，作为这一轮可比较的输入和答案维度。

HMS原有六种细胞，其中MCF10A未加入这一轮背景一致的比较。原因已追到发布层：身份ACH-001357核对正确、文件完整，但24Q4表达与profile索引均未提供其公开RNA记录。另已找到LJP对照和独立RNA-seq，后续可评估这些替代背景的培养及平台差异。这个结论针对固定发布的覆盖，不是“MCF10A没有表达数据”。[原因证据](data_identity.md)

### LINCS Phase II / GSE70138：提供药物处理后的表达响应

**来源：**Broad LINCS的[GEO GSE70138发布](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE70138)。L1000实验测量978个landmark基因，文件另含推断特征。整个发布的Level3有**345,976个实例×12,328个特征**，Level5有**118,050条汇总签名×12,328个特征**。

“实例”是一份具体实验测量；“签名”按发布流程汇总重复并形成相对参照的标准化响应。配套表记录细胞、药物、剂量、时间、检测板、重复ID和药物结构。本轮以**Level5的978维响应z值作为表达答案**，并读取Level3检查原实例、缺失值和同板溶剂对照。

**为什么用：**它既有实际表达数值，也有追到具体给药条件的ID。与下面HMS计数关联时，可以核对项目库板和实际剂量。本轮使用24h表达，固定一个时间点先检验联合预测。这个选择简化了起点问题；尚未用时间比较证明24h最优，3h未进入本轮模型。

### HMS LINCS Joint Project：提供72h功能读数

**来源：**HMS LINCS的[20237](https://lincs.hms.harvard.edu/db/datasets/20237/)、[20238](https://lincs.hms.harvard.edu/db/datasets/20238/)、[20239](https://lincs.hms.harvard.edu/db/datasets/20239/)三个Excel，分别对应三批生物重复。实验在给药72h后成像并识别细胞核数量，另有给药开始及溶剂对照计数。

三个文件共**36,912条孔记录**，覆盖**6种细胞、107个药物、6个剂量**，剂量为0.04、0.12、0.37、1.11、3.33、10 μM。共有**3,852个不同的细胞＋药物＋剂量条件**；保留LJP005/006库板来源时是**4,140条库板条件**，因为部分条件出现在两套库板。

每个孔有这些读数：

| 字段对应的量 | 定义 | 例如0.75表示什么 |
|---|---|---|
| 相对细胞数 | 终点处理组计数Nt / 终点溶剂对照计数Nc | 处理组数量是对照的75% |
| 相对净增长 | (Nt−N0) / (Nc−N0)，N0为给药开始时计数 | 处理组净增加量是对照净增加量的75% |

本轮功能答案选第一项，因为本轮筛选评价就是按终点相对细胞数选择药物；先固定这个可从原孔核算的目标，让各模型使用相同答案。第二项保留供后续比较净增长。这是当前操作定义，并未通过比较证明它是所有任务的最佳终点。相对细胞数同时受到生长与数量减少的影响，解释时继续按“处理/对照计数比”表述。

**为什么先用HMS，而不是直接把GDSC拼进来：**HMS和这批LINCS表达有同项目LJP库板及条件可核对，可以先建立来源清楚的比较起点，再研究跨来源条件关联。它们测量的是平行实验的不同终点：24h表达和72h计数分别保留，不解释为同一个细胞被连续追踪。GDSC仍属于整体框架中的重要扩展来源。

这一步也解释了107药到106药的变化：WH-4-025的`BRD-U60236422`结构字段在当前发布中为`restricted`，未得到可解析的分子结构，暂未进入本轮统一指纹输入。[结构覆盖原表](../data/reference/drug_structure_coverage.csv)

## 其他已收集数据及其接入位置

找这些数据，是为了后续扩大功能覆盖、检查表达的跨实验泛化，并研究细胞群体差异。**下面列的是各来源内部的数量，不是已经与本轮配好的训练样本数。** 本轮144次训练实际使用上一节三个来源。

### 扩展功能观测：保留各实验自己的读数

| 数据与来源 | 文件里是什么、实际有多少 | 为什么需要、接法和当前进度 |
|---|---|---|
| CTRPv2，Broad/CTD²，2015扩展包及2016补充包 | 72h ATP相关活性；2015浓度表**6,171,005行**，实际涉及887个细胞ID、545个处理条目。其中49个是明确的固定比例组合，另有原孔、拟合曲线/AUC及说明表。2016补充含AUC、基线表达及拷贝数；PharmacoSet是同源整理版 | 可扩大实际剂量功能监督。按细胞身份、结构核对药物，保留实测浓度字段`cpd_conc_umol`和聚合实测值`cpd_avg_pv`。已扫描数值并生成条件对应候选；下一步分出单药、核对重复和身份，再形成来源明确的功能长表 |
| GDSC1，Sanger，27Oct23发布 | **5,976,183条原孔记录**，含药物孔及对照，970个细胞名称；其中library单药孔3,179,341条、403个药物ID；另有拟合IC50/AUC。检测为Resazurin/Syto60 | 可增加功能条件并检验跨检测方法的迁移。已核对原孔标签与板级对照；下一步按对照处理强度，再连接细胞、药物和原剂量。孔数保留为孔数，拟合曲线单列 |
| GDSC2，Sanger，27Oct23发布 | **15,069,449条原孔记录**，969个细胞名称；其中library单药孔3,166,905条、296个药物ID；ATP相关强度，另有拟合曲线 | 与GDSC1分别保存来源。下一步按板归一化、核对结构/细胞和剂量，再评估额外监督。已查原始`DURATION=4`与官方72h给药流程的区别，处理时间不直接由该字段改写 |
| PRISM Repurposing 19Q4，Broad | 混合培养后检测各细胞系条形码相对丰度。初筛矩阵**578×4,686**；复筛矩阵**489×13,008**，其中**5,874,229个非缺失数值**，另有处理说明、细胞说明及曲线参数 | 可提供不同药物范围和不同功能实验的外部检验。按`depmap_id`、药物身份及`dose`连接；保留log2相对丰度和120h协议。复筛实际矩阵已检查，尚未纳入本轮模型 |

这些来源的“功能”来自不同测量。后续先比较各自原尺度和条件，再决定如何共享学习：例如共用条件编码、分别预测计数、ATP活性或条形码相对丰度。这里是后续设计，当前没有把这些读数换名合并成HMS标签。

已有的CTRP对接探索先回答“哪些记录值得逐条核对”。按Broad药物ID等元数据初筛，两期LINCS合并范围中，剂量数值相等时有146条对应关系，涉及100个表达条件查询；一条关系是一个表达查询与一条功能曲线的引用，不是一份新实验或一个最终训练样本。保留它们，是为了继续检查药物结构、细胞身份和实际曲线剂量。放宽剂量容差得到的关系另外标记，仍保留原始剂量，尚未进入本轮拟合。[初筛规则和数量](../data/sources/ctrp_candidate_audit.json)

这类单细胞数据保留细胞内部差异，适合研究群体组成和响应。回收到的细胞数量还受捕获与测序影响，因此功能评价继续关联独立计数/药敏；“存活相关状态”的验证也应具体说明独立参考是什么。

文件下载URL与用途见[data/download_manifest.csv](../data/download_manifest.csv)。数量依据来自[逐文件内容清单](../data/sources/file_contents.csv)、[主检查记录](../data/sources/measurement_audit.json)、[GDSC孔检查](../data/sources/gdsc_audit.json)、[MIX-seq检查](../data/sources/mixseq_audit.json)、[NCI检查](../data/sources/nci_audit.json)及[DRUG-seq对象维度](../data/sources/drugseq_dimensions.csv)。主检查记录中的下载进度是当时快照；克隆后的源文件获取以下载清单及下载脚本的实际检查为准。
