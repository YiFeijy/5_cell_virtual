# 表达响应与细胞功能对接的已有研究

核验日期：2026年11月5日。重点是作者实际用了什么数据、如何定义功能标签、如何连接表达与功能。论文中的结果规模不作为本项目当前可训练规模。

**已有工作覆盖了联合预测、表达预测功能、活性相关表达分解和时间状态建模。因此，本阶段先复核这些数据对接方式与假设，比先确定网络结构更有价值。**

## 1 与研究问题最直接相关的工作

| 工作和原始来源 | 数据与标签 | 作者怎样对接 | 本项目能借鉴什么 |
|---|---|---|---|
| [Niepel等 2017](https://doi.org/10.1038/s41467-017-01383-w) | L1000与平行细胞计数、GR | 同项目细胞、药物和剂量；3/24小时表达对应72小时功能 | 用响应与生长两个轴检查一致和不一致情形；不能把有表达响应直接解释成有效杀伤 |
| [Szalai等 2019](https://doi.org/10.1093/nar/gkz805) | LINCS、CTRP；另有RNAi–Achilles | 同细胞、Broad药物ID；最近浓度并限制log10剂量差；遗传扰动按序列映射 | 浓度近似配对的直接先例；遗传fitness和药物活性分别处理；共同死亡相关信号可能掩盖机制 |
| [Dr.VAE 2019](https://doi.org/10.1093/bioinformatics/btz158) | CTRP敏感性与处理前后表达 | 用表达配对和缺少药后表达的样本联合学习；敏感性汇总转换为分类 | 不需要每行都有双标签，但曲线敏感性分类不同于浓度级活性回归 |
| [MIX-seq 2020](https://doi.org/10.1038/s41467-020-17440-w) | scRNAseq与GDSC/PRISM敏感性 | 按细胞系和药物关联；使用AUC；不同平台归一化后汇总 | 原文分解活性相关与活性无关表达，且比较早期表达的预测价值；不是同剂量功能实测配对 |
| [WRFEN XGBoost 2021](https://doi.org/10.1186/s12859-020-03949-w) | LINCS–CTRP及遗传扰动数据 | 最近剂量，log10浓度差不超过0.2；重复活性汇总 | 可复现的简单表达到功能基线；仍须保留不同采样时间和跨平台来源 |
| [MultiDCP 2022](https://doi.org/10.1371/journal.pcbi.1010367) | LINCS、CCLE/TCGA、PharmacoDB | 表达与活性任务利用非完整重叠的数据；曲线拟合后生成选定剂量标签 | 与初步双输出框架接近；区分实测曲线点与拟合生成标签，不要求先制造完整配对 |
| [scTherapy 2024](https://doi.org/10.1038/s41467-024-52980-5) | LINCS2020、PharmacoDB、患者单细胞及验证 | 在LINCS剂量处从药敏曲线插值，结合表达签名和药物指纹预测 | 插值对接的直接先例；患者应用是跨域推断，不能视为患者药后表达与功能全面配对 |
| [CSG²A 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11256952/) | LINCS预训练、GDSC的logIC50 | 先学扰动表达，再迁移到药物敏感性 | 不依赖逐行双标签；作者把下游条件固定为72小时与10 μM是建模设定，不是GDSC浓度级实测恢复 |
| [TranSiGen 2024](https://doi.org/10.1038/s41467-024-49620-3) | LINCS2020 Level3处理前后表达 | 从同条件控制与处理样本构建表征，再用于下游表型任务 | 区分基线绝对表达与扰动签名；需要查清控制匹配和重复使用方式 |
| [SequenTx 2026](https://doi.org/10.1038/s42256-026-01192-1) | LINCS、CTRP与独立验证 | 公开代码先对接表达与活性，再训练状态转移和后续序贯决策模块 | 与长期目标直接相关；单药时间预测成功并不单独证明任意序贯干预的状态可转移 |

## 2 用于数据解释和外部验证的工作

| 工作 | 关键数据事实 | 对本项目的作用 |
|---|---|---|
| [sci-Plex 2020](https://doi.org/10.1126/science.aax6234) | 表达、剂量和细胞异质性；部分viability score来自回收细胞数，并有独立计数验证 | 单细胞状态验证与丰度代理应分开评价 |
| [Combi-seq 2022](https://doi.org/10.1038/s41467-022-32197-0) | 表达衍生活性预测与独立plate活性验证并存 | 只把实际验证条件作为功能真值；表达预测分数可当方法输出 |
| [Way等 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC10246468/) | L1000与Cell Painting的平行表型 | 可比较不同状态读数的互补性；形态变化不能直接改名为活性 |
| [Hafner等 2016](https://doi.org/10.1038/nmeth.3853) | 生长率变化影响传统药物响应解释；提出GR | 有处理前计数时，区分相对细胞数和生长率，不把两者当重复标签 |
| [PharmacoDB 2.0](https://doi.org/10.1093/nar/gkab1084) | 多药敏资源、统一映射和可追溯PharmacoSet | 接入曲线、追踪来源与复现处理的入口；汇总数据库不增加独立样本 |
| [ToxicoDB 2020](https://academic.oup.com/nar/article/48/W1/W455/5838860) | TSet保存表达、条件、LDH和DNA等功能测量 | 在人源肝细胞场景提供另一种响应—功能联合数据路线 |
| [DILImap](https://doi.org/10.1038/s41467-025-65690-3) | 表达与LDH等毒性指标；公开验证数据及部分处理特征 | 分子响应可在细胞死亡之外提供信息；原始训练表达受限，不能按全公开计算可用样本 |
| [scPerturb](https://doi.org/10.1038/s41592-023-02144-y) | 统一单细胞数据格式并追踪原始研究 | 减少预处理工作；仍需继承原实验条件和数据版本，不能创造缺失的功能标签 |

## 3 已核对到代码层的对接规则

**Szalai的原始预处理notebook**已下载到`evidence/cell_death_1_preprocess.ipynb`。主要步骤是：

1. CTRP的`experiment_id`经实验表连接细胞ID，再经细胞表连接名称。
2. `master_cpd_id`经化合物表连接Broad ID。
3. 从QC后的响应表提取`cpd_conc_umol`和`cpd_avg_pv`。
4. 相同细胞、药物、浓度的重复活性取平均。
5. 为每条LINCS条件选择最近的log10浓度，最终保留差值小于0.2的条件，约对应1.58倍浓度范围。
6. 表达签名保持自己的测量时间。一个后期功能标签可能对应多个早期表达记录。

因此它是**跨平台、浓度近似、时间有差异的条件关联**，不是同一实验的严格同步配对。[作者代码](https://github.com/bence-szalai/Cell-death-signatures)。

**MIX-seq作者代码和数据README**已核对：先按细胞与条件汇总表达；`sens`采用`1−AUC`；有多平台数据时，作者对AUC做分位数归一化再汇总。代码还区分viability-related与viability-independent表达效应。该分解是带功能协变量的统计关联，不能直接称为因果机制分离。[作者代码](https://github.com/broadinstitute/mix_seq_ms)。

**SequenTx公开预处理代码**也使用CTRP的QC后浓度级表，通过Broad ID与细胞名匹配最近浓度，并采用log10差值小于0.2的过滤。它是对既有对接路线的继承，不是获取了全新的同实验配对数据。[作者代码](https://github.com/bm2-lab/SequenTx/blob/main/reproducity/CellViabilityModel/01_data_preprocess.py)。

## 4 这些文献如何改变当前方案

1. 先复现清楚的对接，分别研究“表达有变化但功能变化小”“功能变化明显但表达证据弱”等情形。弱表达证据也可能来自时间或测量噪声，不能直接断言没有分子响应。
2. 同时保留两类功能任务：指定浓度终点的读数预测，以及曲线敏感性预测。它们共享部分数据，但标签定义不同。
3. 允许不完整双标签数据参与联合学习，同时设置一个真正有条件对应的队列验证两个任务的关系。
4. 时间建模先从数据支持的3→24小时或6→24小时做起；表达和后续功能各自保留测量终点。
5. 在这些基础验证前，不把JEPA、解耦或状态转移确定为必要模块，也不据此宣称创新点已成立。
