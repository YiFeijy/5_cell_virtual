# 药物分子响应与细胞功能数据可行性审查

核验日期：2026年11月5日。研究范围以人源细胞单药干预为主，并收录可用于外部验证的肝毒性、形态、遗传扰动和组合用药资源。

**已有数据足以开始验证，但应先用实验设计清楚的小队列建立证据，再扩大到跨平台数据。当前最明确的两个入口是 Broad–HMS 联合项目和 MIX-seq。** LINCS–CTRP 是已有文献支持的扩展路线；本轮尚未恢复 CTRP 原始响应表，因此不能声称已完成其交集统计。

`dataset_catalog.csv` 收录43个数据集家族和7个整合或映射资源。家族包含不同发布版本，也可能互相重叠；这不是43个独立的表达—活性配对队列。它是本轮广泛检索的清单，不是对全部公开研究均已穷尽或完成数据级验证的承诺。

## 1 先确定每个读数代表什么

| 读数 | 可以描述什么 | 对接时必须保留的区别 |
|---|---|---|
| 药后表达及相对对照的变化 | 分子状态和通路响应 | 原始表达、log fold change、z-score签名不同；Level5签名不是绝对表达 |
| ATP或代谢染料信号 | 特定assay下的相对功能信号 | 不是逐个细胞的存活判定；归一化和测量时间必须明确 |
| 终点细胞数或相对细胞数 | 一段时间内细胞积累的结果 | 减少可能来自分裂减慢或细胞死亡；需要处理前细胞数进一步区分 |
| GR | 相对生长率的变化 | 与相对终点细胞数具有不同含义；计算需要相应的计数或生长信息 |
| LDH、膜完整性、caspase | 膜损伤或特定死亡过程 | 不同assay不能合并为同一个通用“活性”标签 |
| IC50、GI50、AUC、AAC、DSS | 整条浓度响应关系的汇总 | 不是任意指定浓度的直接活性实测；指标定义和积分范围要分别核对 |
| 回收单细胞数量、细胞周期分数 | 丰度代理或表达推断的状态 | 不能自动作为独立功能实验；表达推导标签与表达预测可能构成循环验证 |

上述区别有直接研究基础：[GR指标原始论文](https://doi.org/10.1038/nmeth.3853)、[NCI增长抑制数据说明](https://wiki.nci.nih.gov/spaces/NCIDTPdata/pages/147193864/NCI-60+Growth+Inhibition+Data)、[Tox21 assay定义](https://ncats.nih.gov/research/research-activities/Tox21/assays)。

因此，本研究首先应验证“哪些分子响应与哪些功能结果相关、何时不相关”，而不是预设表达变化强度等于杀伤强度。[Niepel等的联合实验](https://pmc.ncbi.nlm.nih.gov/articles/PMC5662764/)正是研究这一问题的直接先例。

## 2 已下载并检查的数据

### Broad HMS 联合项目

实际读取 HMS `Screen20237_LJP_processedData1.xls`，其标题注明这是第1个生物学重复内的计数与相对生长数据。表中还包含技术重复、孔位和板号。

| 实际统计项 | 数量或内容 |
|---|---|
| 数据行 | 12,420；包含重复测量，不能当作独立条件数 |
| 细胞系 | BT20、HS578T、MCF10A、MCF7、MDAMB231、SKBR3 |
| 化合物 | 107个Broad ID |
| 浓度 | 0.04、0.12、0.37、1.11、3.33、10 μM |
| 功能终点 | 72小时 |
| 去重后的细胞—药物—浓度条件 | 3,852 |
| 已有功能字段 | 处理前细胞数、处理后细胞数、对照细胞数、相对细胞数、相对生长率 |

将这些条件与下载的LINCS Phase I、Phase II完整签名元数据匹配，只纳入LJP前缀、小分子、正浓度和可解释单位的记录：

| 来源 | 表达时间 | 匹配签名记录数 | 去重条件数 |
|---|---:|---:|---:|
| GSE70138 | 3小时 | 4,135 | 3,847 |
| GSE70138 | 24小时 | 4,202 | 3,838 |
| GSE92742 | 6小时 | 516 | 516 |
| GSE92742 | 24小时 | 502 | 502 |

3,852个功能条件均能在上述表达元数据中找到对应。跨时间匹配限定在同一个数据版本内：GSE70138有 **3,835个3小时与24小时共同条件**；GSE92742有 **502个6小时与24小时共同条件**。不同来源的共同条件不能相加当作独立轨迹。

这是**条件层面的候选对应关系**：采用相同细胞名、Broad ID和数值浓度。表达矩阵尚未下载，表达质量、实验批次和不同LJP批次的实际归属仍需核对。平行孔和破坏性采样也不构成对同一个细胞的连续追踪。

输入可用性还有两个实际缺口：107个药物中，当前已下载的Phase I药物表仅能提供93个的结构字符串，14个仍缺结构；6个细胞都能映射到DepMap模型，但固定24Q4发布仅有5个能在默认RNA profile索引中找到记录，MCF10A没有默认RNA记录。按这两项筛选，功能候选条件为2,790个，其中2,781个同时有同版本3小时与24小时表达元数据。这不等于这些信息在所有资源中均不存在；它说明**3,852个条件尚不能直接全部进入原方案的“CCLE基线加药物结构”模型**。可继续补结构、查其他基线来源，或改用同实验L1000对照作为状态背景。

已保存细胞及药物映射、全部候选对应行、字段字典和可重算脚本。原始功能表与论文补充表属于不同文件范围，不能用其中一个的行数替代另一个。[官方数据表目录](https://lincs.hms.harvard.edu/db/datasets/)、[原始联合实验论文](https://doi.org/10.1038/s41467-017-01383-w)。

### MIX seq 实际试读

下载并读取作者Figshare的4个原始表达包：trametinib 6小时、24小时，以及各自DMSO对照。核对了矩阵、基因表、barcode和细胞注释的对应关系；使用作者标为`normal`的单细胞。

| 条件 | 原始矩阵细胞数 | normal细胞数 |
|---|---:|---:|
| DMSO 6小时 | 2,056 | 1,886 |
| DMSO 24小时 | 2,831 | 2,623 |
| Trametinib 6小时 | 2,789 | 2,560 |
| Trametinib 24小时 | 3,077 | 2,825 |

合计9,894个normal细胞。原始补充表确认trametinib浓度为0.1 μM。24个细胞系在四个条件中各有至少20个normal细胞，并能对接作者提供的敏感性标签。已导出条件级原始计数伪bulk，保留基因顺序和DepMap ID。

**这里的功能标签是作者处理后的`1−AUC`敏感性，涉及PRISM/GDSC归一化与汇总；它不是0.1 μM下的直接活性实测。** 该试读支持验证“早期表达与整条药敏曲线敏感性的关联”，不能直接定义为“6小时表达预测72小时指定浓度存活率”。目前也只有一个药物的原始表达试读，不能据此验证跨药物泛化。[原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7453022/)、[作者原始数据](https://doi.org/10.6084/m9.figshare.10298696)。

### 其他元数据核验

- **LINCS**：实际读取473,647行Phase I、118,050行Phase II签名元数据；这是全扰动类型的元数据行数。按小分子、正浓度、单位和时间筛选后，分别剩204,959与107,369条签名记录；仍未做矩阵质量筛选。实际基因表确认978个landmark基因。Phase I的`pert_idose`可能是舍入后的显示剂量，数值匹配优先使用`pert_dose`及单位。
- **PRISM secondary**：已读官方README及处理、细胞元数据。处理表有13,008行、1,448个名称、1,502个完整Broad ID，显示名称、化合物身份和批次不能混为一种计数。细胞表588行包含对照及STR问题记录，不能直接当588个合格实验细胞系。响应矩阵尚未读取。[官方发布](https://depmap.org/repurposing/)。
- **Tahoe**：已读官方药物、样本和细胞注释Parquet。药物表379行、样本表1,344行；细胞注释表1,000行是驱动事件注释，包含102个Cellosaurus ID，比论文描述的表达面板更广。**不能用注释表的ID交集替代实际表达交集**。已查看字段中没有独立活性标签；也没有逐样本时间列，需回查实验方法。[官方数据卡](https://huggingface.co/datasets/tahoebio/Tahoe-100M)。
- **DepMap**：固定下载24Q4模型、默认profile和profile索引，HMS六细胞均有稳定模型ID，五细胞有默认RNA profile索引。表达矩阵未下载；索引可用不等于表达数值和质量已核验。跨实验CCLE基线不能冒充L1000同板DMSO对照。[固定发布API](https://api.figshare.com/v2/articles/27993248)。

完整机器可读结果见`audit/audit_results.json`、`audit/mixseq_pilot_audit.json`和`audit/field_dictionary.csv`。

## 3 应优先使用哪些路线

| 路线 | 当前用途 | 主要限制 |
|---|---|---|
| Broad–HMS联合项目 | 先验证表达与功能的共同及不同部分，再研究3小时到24小时变化 | 细胞背景较窄；需补表达矩阵、QC和批次核对 |
| MIX-seq | 单细胞异质性、早期响应与长期敏感性关联 | 药物较少；现成标签主要是曲线汇总而非浓度级活性 |
| LINCS–CTRP | 文献成熟的跨平台浓度近似对接 | 本轮原始响应文件未恢复；终点不同；阈值敏感性和标签复用要检查 |
| LINCS–GDSC或PRISM | 扩展功能监督与跨平台验证 | 需要raw浓度级数据；身份及assay差异；单浓度PRISM不能生成完整曲线 |
| NCI TPW与DTP | 多时间表达、GI50或浓度曲线关联 | 药物面板有限；GI50和表达处理浓度不能混同 |
| Open TG-GATEs human与DILImap | 若允许扩展到肝细胞，可研究分子响应与毒性读数的关系 | 非肿瘤场景；DILImap训练原始表达并非全面开放 |
| sci-Plex、Tahoe、Novartis、VCPI | 增加响应预测数据及外部状态验证 | 不能默认包含独立功能标签；部分资源需注册或申请 |

[NCI TPW官方页面](https://tpwb.nci.nih.gov/GeneExpressionNCI60/index.html)、[ToxicoDB的联合读数说明](https://academic.oup.com/nar/article/48/W1/W455/5838860)、[DILImap数据开放范围](https://pmc.ncbi.nlm.nih.gov/articles/PMC12615732/)。

## 5 复现本轮结果

在项目根目录运行，环境需要Python的pandas、numpy、scipy、pyarrow，以及基础R。读旧Excel所需的纯Python xlrd wheel已保存在evidence中，脚本按路径导入，不修改全局环境。

```bash
python3 数据可行性调研_20261105/scripts/build_catalog.py
python3 数据可行性调研_20261105/scripts/fetch_metadata.py --include-expression
python3 数据可行性调研_20261105/scripts/audit_metadata.py
Rscript 数据可行性调研_20261105/scripts/audit_mixseq.R
python3 数据可行性调研_20261105/scripts/audit_mixseq.py
```

`download_sources.csv`记录来源，`audit/downloaded_file_manifest.csv`记录本地文件大小和SHA256。对应关系表保留表达和功能终点，后续不得用一个`time_h`覆盖两个assay的时间。
