# 当前HMS核心对接产物

本目录为当前核心对接的v2准备结果。先阅读[数据内容 处理步骤与设计原因](../../investigation_20261106/当前对接说明_数据内容处理步骤与设计原因.md)。

v2使用HMS实际库板LJP005/006，以及细胞、药物ID和数值剂量建立连接。三个生物重复内先汇总技术孔，再在同库板内等权汇总生物重复。其他LJP库板的78条签名另行保留。

当前输入与观测齐全的范围为五细胞、106药物、3,168个独特给药条件。保留库板后有3,407条记录，对应6,814条表达签名。相同给药条件在两个库板的记录使用同一条件组ID，后续划分整体分组。

- `核心库板条件表.csv`：背景身份、药物结构、剂量、两表达签名、功能及重复。
- `核心表达签名矩阵.npz`：6,814×978，包含签名ID及Entrez基因ID。
- `核心表达签名与矩阵行号.csv`：矩阵定位、原签名条件和指标。
- `CCLE背景矩阵_与表达基因同顺序.csv`：5×978，使用同一基因顺序。
- `库板内生物重复与技术孔引用.csv`：全部HMS库板条件的生物重复，以及源Excel行号引用。
- `核心表达功能关系表.csv`：按表达时间展开的关系，保留一个功能终点的归一权重。
- `v2实际进度.json`：逐单位计数与实际完成层级。

已完成来源、数值条件和导出对应核对；最终生物学质量入组、输入定义、身份复核和划分仍需实施。当前没有训练模型。父目录中的v1表保留为较宽的条件候选审计记录。
