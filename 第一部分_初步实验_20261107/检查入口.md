## 2. 原始数据是什么、在哪里

| 数据来源与实验读数 | 本地文件 | 本轮作用 |
|---|---|---|
| CCLE/DepMap 24Q4，未处理细胞的基因表达，log2(TPM+1) | [原始表达矩阵](../data/raw/CCLE_DepMap_24Q4/OmicsExpressionProteinCodingGenesTPMLogp1.csv)；同目录Model及RNA profile表用于身份核对 | 给药前细胞背景输入；这里5个细胞，取与LINCS一致的978个基因 |
| LINCS GSE70138，药物处理后的L1000表达实验；本轮目标采用24h、Level5的标准化响应z值 | [原始下载目录](../data/raw/LINCS_GSE70138/)；[解压后的GCTX目录](../data/unpacked/LINCS_GSE70138/) | Level5提取978基因目标；Level3及实例元数据用于处理实例、对照、条件核对 |
| HMS LINCS平行计数实验，72h相对细胞数，处理组细胞数/对照组细胞数 | [第1批](../data/raw/HMS_LINCS/Screen20237_LJP_processedData1.xls)、[第2批](../data/raw/HMS_LINCS/Screen20238_LJP_processedData2.xls)、[第3批](../data/raw/HMS_LINCS/Screen20239_LJP_processedData3.xls) | 功能目标：先汇总每批技术孔，再平均三批生物重复；1表示与对照相当，0.75表示细胞数约为对照的75% |

HMS与LINCS依据库板、细胞、药物、实际剂量对应；二者是相应条件的平行实验。CCLE背景来自另一个实验。表达响应z值与CCLE背景的log2(TPM+1)分别保留，表示不同测量。

## 3. arrays.npz里到底有什么

3364条库板观测对应3133个不同的细胞＋药物＋剂量条件；同条件跨库板出现时按权重合计为1。包含5个细胞、106个药物。细胞为SKBR3、MCF7、HS578T、BT20、MDAMB231，索引见[细胞索引表](检查样本/细胞索引表.csv)。

| 字段 | 形状 | 含义 |
|---|---|---|
| `baseline` | 5×978 | 输入：每个细胞的给药前表达，log2(TPM+1) |
| `drug_morgan` | 106×2048 | 输入：每个药物的0/1结构指纹 |
| `cell_index`、`drug_index` | 各3364 | 每条观测应该取哪一行细胞背景和药物指纹 |
| `log10_dose_uM` | 3364 | 输入：以μM计的剂量取log10 |
| `expression_z24` | 3364×978 | 监督答案：实测24h响应z值 |
| `count72` | 3364 | 监督答案：实测72h处理/对照细胞数比值 |
| `condition_weight` | 3364 | 观测权重，控制同条件的跨库板重复 |
| `gene_id` | 978 | 所有基因维度的统一顺序 |
| `library_condition_id` | 3364 | 与样本清单、来源表对应的观测ID |

本轮时间固定为24h表达和72h计数。3h未进入训练。模型的`forward(cell, drug, dose)`只接收三类给药前输入；实测表达和细胞数用于计算训练误差、评价预测。

普通联合模型：978维背景→128维，2048位药物→128维，剂量→32维；拼接288维→共享128维；分别输出978个响应值与1个细胞数值。输入缩放参数及功能目标缩放参数仅由相应训练集计算，保存在每次训练目录。

## 4. 从一条真实观测走到预测

打开[样本条件与前向核查.json](检查样本/sample_311/样本条件与前向核查.json)。

- 样本：`sample_index=311`，BT20，afatinib，0.04 μM，LJP006库板；观测ID为`HMSv2_LIB_175ffaa50568acca`。
- 细胞输入取`baseline[3]`的978个值；药物输入取`drug_morgan[7]`的2048位；剂量输入为log10(0.04)，再用该折训练统计量缩放。
- 实测表达签名为`LJP006_BT20_24H:G24`，对应三个原始实例；978个真实响应值取`expression_z24[311]`。
- 三批计数均值分别为0.7229533、0.7682533、0.7625167，最终目标为**0.7512411**。原文件及技术孔引用见[72h重复表](检查样本/sample_311/72h原始功能重复及孔引用.csv)。
- 在`unseen_drug`第1折中，该药物作为测试药物留出。使用`joint_shared`、种子20261107的已保存模型，重新前向计算得到**0.8065399**。这是一个测试折、一个种子的预测；用来核对代码和数据，方法表现须看完整测试结果。
- 重算与保存测试预测的差异：细胞数约1.22×10⁻⁸，表达最大约5.07×10⁻⁷，符合单样本与批量浮点计算差异。

这次模型的原始产物都在[runs/unseen_drug__fold1__joint_shared__seed20261107/](runs/unseen_drug__fold1__joint_shared__seed20261107/)：`model_state.pt`是权重，`preprocessing.npz`是缩放参数，`history.csv`是训练历史，`test_predictions.npz`是测试预测，`complete.json`是运行记录。

## 5. 自己运行检查

在项目根目录执行，使用本轮环境的Python：

```bash
cd /home/data2/jiangyun/5_cell_virtual/3_MVP
python3 第一部分_初步实验_20261107/scripts/inspect_one.py
```

[inspect_one.py](scripts/inspect_one.py)读取已有数组、划分、缩放参数和权重，只重新计算一条样本并导出CSV，不启动训练。也可通过`--sample-index 其他行号`检查另一条样本。默认输出在[检查样本/sample_311/](检查样本/sample_311/)。

直接读取全部训练数组：

```python
import numpy as np
import pandas as pd

folder = '第一部分_初步实验_20261107/data/'
samples = pd.read_csv(folder + 'samples.csv')
with np.load(folder + 'arrays.npz', allow_pickle=False) as a:
    i = 311
    cell = a['baseline'][a['cell_index'][i]]
    drug = a['drug_morgan'][a['drug_index'][i]]
    dose = a['log10_dose_uM'][i]
    target_expression = a['expression_z24'][i]
    target_count = a['count72'][i]
    print(samples.loc[samples.sample_index.eq(i),
                      ['cell_id', 'pert_iname', 'dose_uM', 'sig_id']])
    print(cell.shape, drug.shape, dose, target_expression.shape, target_count)
```

建议检查顺序：本页 → 样本CSV及默认样本导出 → train.py的Model和forward → 具体训练目录 → 汇总结果。数据来源有疑问时，再沿上游引用追到原始文件。
