# 抗癌药物筛选：表达响应与细胞功能联合建模

我们研究：能否根据给药前细胞背景、药物结构及剂量，预测药物引起的表达变化和功能后果，并帮助选择值得实验验证的药物。

整体框架依次研究单药、新细胞迁移、同时联合、序贯和方案评价。当前完成的是**第一部分的一轮单药比较**：先建立来源清楚的数据，再检验表达与功能共同学习是否有用。

## 本轮从什么数据开始

| 信息 | 实际来源和内容 | 模型中的作用 |
|---|---|---|
| 给药前细胞背景 | CCLE/DepMap 24Q4基线RNA | 输入978个基因的log2(TPM+1) |
| 药物及剂量 | LINCS药物结构与实验条件 | 输入2048位指纹和log10剂量 |
| 药后表达 | LINCS Phase II 24h实测landmark响应 | 预测978维z响应 |
| 功能后果 | HMS平行实验72h处理/对照细胞数比 | 预测1个相对计数值 |

按库板、细胞、药物、实际剂量建立对应，保留两个实验终点。最终为**5种细胞、106药、3,364条库板观测、3,133个不同条件**。其他数据的内容、数量和接入方法在第02页逐个交代；它们未混入这一轮训练。

## 已经得到什么

| 问题 | 已有结果 | 当前判断 |
|---|---|---|
| 联合学习是否改善新药预测？ | 细胞数MAE：单任务0.2371，普通联合0.2340，细胞×剂量均值0.2313 | 联合相对单任务的小幅变化尚不稳定，也未超过强简单参照 |
| 是否帮助高剂量外推？ | 单任务0.1337，普通联合0.1252，表达误差也降低 | 在本次已知药物高剂量设置下有改善信号 |
| 选出的药是否更好？ | 新药前5选择差距：单任务0.2923，普通联合0.2991，越低越好 | 本轮排序没有改善 |
| 实测表达是否包含功能信息？ | 改用实测24h完整响应预测72h计数，MAE为0.1252 | 表达中有可利用的预测信息；这是需要额外观测的补充诊断 |

因此下一步先定位新药表达和药物差异的预测误差，再检验额外表达监督、多来源功能数据和独立状态参考的价值。当前结果是后续设计的依据，没有把共享向量直接当成已验证的存活状态。

## 直接检查一次真实预测

```bash
python -m pip install -r requirements.txt
python src/check.py
python src/inspect_one.py
```

默认例子：BT20＋afatinib＋0.04 μM，实测72h相对细胞数**0.7512411**，附带测试折模型预测**0.8065399**。输入、答案、预测及三批计数见[examples/sample_311](examples/sample_311)。运行不会启动训练。
